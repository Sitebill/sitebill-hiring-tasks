# sitebill-hiring-tasks

Тестовые задания команды [Sitebill](https://www.sitebill.ru) для разработчиков. Открытый репозиторий, чтобы вы
могли заранее посмотреть, что вас ждёт, и оценить, интересна ли вам работа с нашим стеком:
Laravel, Nuxt, Python и мультитенантная платформа для недвижимости.

Вакансии и отклики: <https://www.sitebill.ru> (раздел «Вакансии»).

## Как устроен отбор

1. Короткий звонок.
2. Тестовое задание (общая часть около часа, задача по роли до 3 часов): сначала **обязательная** общая часть (поднять нашу бесплатную версию и получить лицензию на обновления полным путём клиента: регистрация, заказ с промокодом, ключ),
   затем задача по вашей роли.
3. Разбор: вы показываете решение, мы задаём вопросы «почему так» и просим внести небольшую правку.
4. Оплачиваемый пробный период.

Задания в этом репозитории вы получаете **только после звонка**, но заглянуть сюда заранее можно.
Если задача вам интересна сама по себе, решайте её для практики, ничего не отправляя.

## Правила

- **Решайте в приватном репозитории**, а не в публичном форке. Так честнее для тех, кто решает после вас.
- ИИ-ассистентами пользоваться можно. На разборе вы объясняете любую строку.
- Если задание неясно, спросите. Хороший вопрос лучше молчаливой догадки.
- Не отправляйте нам реальные персональные данные. Все данные в заданиях тестовые.
- Задание не используется в нашем продукте без отдельной договорённости и оплаты.
